# CPP

## CPP00 - Learned Concepts

### ex00: Megaphone

- Reading command-line arguments with `argc` and `argv`.
- Using standard output streams (`std::cout`) to display results.
- Character handling and uppercase conversion with `std::toupper`.
- Iterating through strings and handling the no-argument case.
- First approach to C++ style (standard library, `std::string`, `std` namespace).

### ex01: PhoneBook

- Introduction to object-oriented programming with classes (`Contact`, `PhoneBook`).
- Data encapsulation and separation between interface (`.hpp`) and implementation (`.cpp`).
- Organizing a multi-file C++ mini-project with a `Makefile`.
- User interaction through a command loop (`ADD`, `SEARCH`, `EXIT`).
- Robust input handling with `std::getline` and text fields.
- Formatted display of a contact table (alignment, truncation, presentation).
- Managing a fixed-size contact storage (replacement logic when the phonebook is full).
- Reinforcing core best practices: readability, structure, and class responsibilities.
